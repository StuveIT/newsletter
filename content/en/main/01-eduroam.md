title: eduroam - Important Notice
---

To use the campus-wide “eduroam” Wi-Fi service, all users need an up-to-date configuration profile.  
The current “Uni Konstanz” profile is valid only until October 28, 2026, as the certificate it contains is set to expire.  
Therefore, it must be renewed before then if you wish to continue using eduroam.

You can find instructions for renewal on the KIM website at the following link:  
<div class="flex-grid slot">
  <a href="https://www.kim.uni-konstanz.de/en/email-and-internet/wi-fi-wlan/wlan-wi-fi-access/">Wifi-Access</a>
</div>

The procedure is documented for each operating system. If you have any problems or questions, please contact [support@uni-konstanz.de](mailto:%20support@uni-konstanz.de) or ask at the help desk in the library.
